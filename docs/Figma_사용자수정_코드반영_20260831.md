## 유지한 계약

- 일반 `Button.small`은 32px. SectionHeader에 넣은 입력 등 별도 액션의 고유 크기는 유지.
- 명시적 액션 variant·폭·라벨·disabled·콜백과 커스텀 footer 우선순위 유지.
- 푸터 없는 경우 유지. 4번째 이후 생략 variant는 기존 fillBlack 유지.
- CenterModal·SideSlidePanel의 취소·X·Esc 공통 dismiss 동작 유지.
- 기존 화면에 명시된 색상을 일괄 교체하지 않음. 전체 MES 화면·기타 Figma 자산 전수 반영으로 확대하지 않음.

## 검증

- 최종 `npm run verify:full` 통과: 브라우저 검사 **92/92**, 디자인 시스템 검사·lint·TypeScript·정적 빌드 통과. 별도로 수정한 UI 6개 파일의 ESLint도 통과.
- 이번에 확인한 공용 컴포넌트 5종과 SectionFrame 연동 반영 완료. Git 커밋·푸시는 수행하지 않았다. 전체 Figma 자산 작업은 별도 진행 범위로 남는다.
- 회귀 검사: [figma-component-defaults.spec.ts](../component-library/tests/visual/figma-component-defaults.spec.ts).
- 재현 경로: `/visual-regression/figma-component-defaults/` — 공용 컴포넌트 테스트 전용.
- 높이·배경색·폭·radius·간격을 실제 브라우저 계산값으로 검사한다. 지정값·숨김·동작 호환도 검사한다.
- Figma→코드 스킬에 따라 기존 MES 컴포넌트와 토큰을 재사용했다. 문서·자산 원장은 기존 동기화 명령으로 갱신한다.
- 전체 파이프라인 실행 결과는 [전체 검증 결과](전체_검증_결과.md)에 자동 기록한다. 이 문서의 반영 범위가 전체 프로젝트 완료를 의미하지는 않는다.

### 기준 이미지 변경 검토

첫 전체 실행은 92개 중 84개 통과·8개 이미지 비교 실패였다. 차이 이미지를 직접 대조한 뒤 영향받은 8개 테스트의 기준 이미지 9장을 갱신했다.

- 재고 추가·발주 정보·일괄 출하승인·품목 생산량·표준단가·조 설정: 공용 확인 버튼을 새 파란 기본값으로 갱신.
- 캐비티: 제목 행 32→28px에 따른 본문 위치와 확인 버튼 갱신.
- 양식 편집·입고검사: 제목 행 외곽28px에 따른 본문 위치 갱신. 양식 편집의 제목 옆 버튼도 28px.
- 양식 편집·입고검사 캡처 배경: 현재 카탈로그의 승격 자산/Tier 순서를 반영. 해당 메뉴 코드는 이번 작업에서 수정하지 않았다.
- 지정값을 가진 다른 화면의 색상은 그대로 유지했으며, 이미지 허용 오차나 기존 동작 검사는 완화하지 않았다.
