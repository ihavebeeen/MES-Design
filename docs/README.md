## 문서 관리 규칙

- 현재 정책, 과거 감사 기록, 자동 생성 결과를 한 문서에 섞지 않는다.
- 같은 주제의 `1차`, `완료`, `TODO` 문서는 작업이 종결되면 하나의 이력 문서로 합친다.
- 모든 컴포넌트에 장문의 실제 사용처를 만들지 않는다. 선택을 바꾸는 핵심 규칙만 상세 계약으로 관리한다.
- 한 화면에서만 관찰된 사용 방식은 공통 규칙으로 승격하지 않는다.
- 문서를 합칠 때 고유한 결정, 예외, 근거와 보류 사유는 남긴다.
- 파일 경로나 정책이 바뀌면 문서 링크 검사와 `npm run check:design-system`을 함께 실행한다.
