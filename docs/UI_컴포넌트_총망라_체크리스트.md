# UI 컴포넌트 전체 목록 안내

이 문서는 더 이상 현재 상태 원장으로 사용하지 않는다. 과거 표 형식의 216개 후보는 기계 판독 가능한 `component-library/src/design-system/registry/tier-candidates.json`으로 이관했다.

현재 상태는 다음 자료에서 확인한다.

- 자산 전체: `component-library/src/design-system/registry/asset-manifest.json`
- 컴포넌트별 문서: `docs/components/README.md`
- Tier 판정: `docs/UI_컴포넌트_티어_정규화.md`
- 사용 맥락: `component-library/src/design-system/registry/component-usage-contracts.json`
- MES 공통 규칙: `docs/MES_디자인_시스템_규칙.md`

과거의 장문 작업 이력과 당시 숫자는 Git 이력에서 확인할 수 있으며, 현재 AI 판단 근거로 사용하지 않는다.
