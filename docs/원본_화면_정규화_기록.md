# MES 원본 화면 정규화 기록

## 목적

Figma에는 최초안, 부분 수정안, 반응형안, 상태 예시가 함께 남아 있다. 이를 각각 독립 화면으로 복제하지 않고, AI와 개발 코드가 재사용할 수 있는 `기준 화면 + 상태 + 보조 팝업 + breakpoint` 구조로 정규화한다.

## 판단 규칙

1. 업무 목적과 데이터 흐름이 같으면 같은 화면이다.
2. 일부 열, 툴바, 카드, 입력 상태만 달라졌다면 최신 변경을 기준 화면에 합치고 이전안은 근거로만 남긴다.
3. 선택 전/후, empty/populated, 편집 활성/비활성은 화면 복제본이 아니라 state다.
4. 같은 화면의 1280·786·375 시안은 breakpoint다.
5. 목록에서 링크나 버튼으로 열리는 상세·설정 화면은 상위 화면의 보조 팝업이다.
6. 구현은 기존 Button, Input, Select, Radio, Checkbox, Table, Filter, SearchInput, CenterModal을 우선 사용한다.

## 구현된 상호작용

- 양식관리: 목록 체크, 편집/기준설정/검사 팝업 열기와 닫기
- 생산실적: 1280/786/375 전환, 체크 상태
- 캐비티: 자동/사용자 설정, 셀 선택, 반전 시 사용자 설정 전환, 초기화, 번호 교환
- 재고 추가: 행 체크, 선택 행 상단 고정, 선택 행 입력 활성
- 재고편집: 행 선택, 플로팅 선택 툴바, 이동/삭제 보조 모달
- 발주 정보: 행 선택, 품목 건수 링크, 품목 상세 보조 모달
- 생산분석: 당월/당일, 금액/수량, 판매·생산 계획 설정 카드
- 냉각기 점검표: 기간 조회, 필터·검색, 회색 미선택/검정 선택/파란 행, 삭제, 복사·CSV 다운로드, 점검 결과 등록 요청
