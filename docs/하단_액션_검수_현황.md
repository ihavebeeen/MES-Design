# 하단 액션 검수 현황

하단에 버튼이 렌더링된다는 사실과 Figma 원본의 버튼 개수·순서·폭·색·동작을 검증했다는 사실을 구분한다. 기계 판정 원본은 `component-library/src/design-system/registry/footer-action-audit.json`이다.

## 현재 집계

| 분류 | 화면 |
| --- | --- |
| 원본 검증됨 | 양식관리 검사 기준, 사용자 정보·비밀번호, 판매관리·거래명세서, 출하승인, 총 생산수량 변경 |
| 구현됐으나 원본 개별 검수 남음 | 이지모드 입고등록 |
| 코드화·검수 큐 | 설비별 토출량 설정, 표준단가 설정, 조 설정 |
| 하단 액션 대상 아님 | 냉각기 점검표 조회형, 공정검사 경향관리 전체 화면 |

따라서 현재 상태는 `전체 배치 완료`가 아니라 `일부 검증 + 일부 미검수`다. 새 화면을 추가할 때는 source evidence와 함께 이 장부에도 항목을 추가해야 한다.
