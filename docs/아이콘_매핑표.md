# 아이콘 매핑표 (mes/icon-* ↔ lucide-react)

출처: 클라우드MES 파일(fileKey `F4n5Zr04PAbiRjfIFQAo6v`) node `9873:81854`("area") →
`9873:81855`("icon component") — 아이콘 컴포넌트 전체 시트, 40개 아이콘 패밀리 확인.

## 왜 실제 SVG를 못 가져오는지 (환경 제약, 이번에 재확인)

이 노드를 받은 뒤 실제 벡터를 받아보려고 아래 두 가지를 시도했고 **둘 다 실패**함(기존에
Select/Combobox 등에서 아이콘 대체할 때 확인했던 것과 동일한 제약이 이번에도 그대로 재현됨):

1. `download_assets` 툴로 `mes/icon-x`(node 9873:81991) SVG export 요청 → Figma가 임시
   다운로드 URL(`https://www.figma.com/api/mcp/asset/...`)을 줌
2. 그 URL을 `curl`로 직접 받기 → `HTTP 403`(프록시 차단)
3. 같은 URL을 `mcp__workspace__web_fetch`로 받기 → 빈 응답(차단)

즉 이 작업환경 자체가 Figma 애셋 CDN에 네트워크로 접근을 못 하게 막혀 있음 — 노드를 받고 안
받고와 무관하게 구조적 제약이라, 파일을 몇 개를 더 줘도 이 방식으로는 실제 SVG를 못 얻음.

**대신 확보한 것**: `get_screenshot`을 `enableBase64Response=true`로 호출하면 이미지가 내
응답 안에 직접 인라인으로 포함돼서(외부 URL을 따로 못 가져와도) 아이콘 40개 전체를 육안으로
확인할 수 있었음. 이걸로 아래 표를 작성함 — 벡터 좌표 실측은 아니고 "육안 비교"라서, 지금까지
쓴 "이름만 보고 추측"보다는 낫지만 여전히 대체재(substitute)지 실측치가 아님.

**실제 SVG가 필요하면**: 담당자가 Figma에서 직접 해당 아이콘을 선택 → 우클릭 "Export" → SVG로
내보내서, 저장소 폴더(예: `component-library/public/icons/`)에 넣어주면 내가 바로 정확한
벡터로 교체 가능. 나는 못 당겨오지만 담당자가 밀어넣는 건 됨.

## 확신도 기준

- ◎: 24px 썸네일로도 형태가 명확해서 lucide 대체가 사실상 확실함
- △: 형태가 애매하거나(작은 썸네일 한계) 이름과 형태가 안 맞아 보이는 경우 — 실제 사용 전
  담당자 확인 또는 더 큰 배율 스크린샷 재확인 권장
