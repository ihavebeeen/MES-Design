# IconMenu

> `icon-menu` · icon · Tier 2 · stable · 내부 조립용

## 역할

등록된 MES 메뉴·업무 의미와 일치하는 벡터 아이콘을 표시한다.

## 생성 선택 기준

- 등록된 MES 메뉴·업무 의미와 일치하는 벡터 아이콘을 표시한다.

선택하지 않는 경우:
- 의미가 다른 아이콘을 장식으로 재사용하거나 동작 컴포넌트를 대신하는 경우

## API와 상태

- 공개 심볼: `IconMenuProps`, `IconMenu`
- 주요 Props: `size`
- 상태: 정적 표시
- 변형: 등록된 별도 variant 없음

## 접근성과 제약

- 네이티브 의미와 부모 컨텍스트의 접근 가능한 이름을 유지합니다.
- 화면 코드에서 직접 호출하지 않고 부모 컴포넌트 내부에서만 사용합니다.

## 근거

- 구현: `src/components/icons/icon-menu.tsx`
- 웹 문서: 웹 탐색에 노출하지 않음
- 생성 선택 맥락: 적용됨
- 상세 선택 계약: 기본 맥락만 적용
- 참고 화면: 없음
- 참고 화면의 역할: 직접 화면 근거 없이 의미·API 맥락으로 정의

이 문서는 `npm run sync:assets`로 생성합니다. 직접 수정하지 않습니다.
