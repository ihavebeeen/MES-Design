# MES 디자인 시스템

우리 MES의 버튼, 입력창, 표, 팝업과 화면 배치 규칙을 모아둔 프로젝트입니다.
이 자산을 활용해 AI에게 새 화면을 만들거나 기존 화면을 수정해 달라고 요청할 수 있습니다.

## 무엇을 할 수 있나요?

- 색상·폰트·간격과 컴포넌트의 모양·동작을 확인할 수 있습니다.
- 목록, 중앙 팝업, 우측 슬라이드 팝업 등의 구성 예시를 볼 수 있습니다.
- 업무 목적과 필요한 기능을 설명하면 AI가 MES 자산으로 화면을 만듭니다.
- 생성된 화면을 브라우저에서 확인하고, 배치나 동작을 수정해 가며 다듬을 수 있습니다.

## 내 PC에서 열기

Node.js와 Git을 준비하고, 이 저장소를 내려받습니다.
`MES-Design` 폴더에서 Git Bash를 열어 실행합니다.

```bash
cd component-library
npm ci
npm run dev
```

`npm ci`는 실행에 필요한 파일을 설치합니다. 처음 내려받았거나 설치 목록이 바뀌었을 때 실행합니다.
다음부터는 `component-library` 폴더에서 `npm run dev`만 실행하면 됩니다.

터미널에 표시된 주소를 브라우저로 엽니다. 기본 주소는 [localhost:3000](http://localhost:3000/)입니다.
상단 탭과 좌측 목록에서 컴포넌트·패턴·원본 화면을 살펴볼 수 있습니다.

## AI에게 화면 요청하기

Codex 같은 AI 작업 도구에서 이 저장소를 열고, 아래처럼 요청합니다.

> 이 저장소의 .agents/skills/generate-mes-ui/SKILL.md를 읽고,
> 품목별 재고를 조회하는 화면을 만들어줘.
> 품목명으로 검색하고 창고별로 좁혀 볼 수 있어야 해.
> 한 품목을 선택하면 LOT별 재고를 확인하고 싶어.
> 우리 MES 디자인 시스템으로 만들고, 내 PC에서 먼저 볼 수 있게 해줘.

함께 알려주면 좋은 내용은 **누가 어떤 일을 하는 화면인지, 어떤 정보와 기능이 필요한지**입니다.
원하는 화면 유형이나 참고 이미지가 있으면 함께 전달합니다. 중요한 정보가 부족하면 AI가 질문합니다.

AI는 기존 자산을 선택해 구현하고 코드·화면·동작을 확인한 뒤 미리보기 주소를 안내합니다.
결과를 보고 “이 영역은 더 좁게”, “선택한 행만 수정 가능하게”처럼 수정 요청을 이어가면 됩니다.

## 만든 화면 보관하기

생성 시안은 우선 해당 PC의 임시 미리보기로 저장합니다.
Git에 남기고 싶으면 AI에게 **“이 시안을 저장소에 보관해줘”**라고 요청한 뒤 변경 내용을 확인해 커밋·push합니다.
공통 컴포넌트나 기준 화면으로 채택할 때는 별도로 승인합니다.

다른 PC에서도 저장소를 내려받아 설치한 뒤 같은 방식으로 화면을 만들고 확인할 수 있습니다.
PC 사이에서 공유할 작업은 Git에 보관합니다.

## 지금 진행하는 것

- 웹: 기존 자산과 사용 규칙을 활용해 화면을 만들고, 생성 과정에서 필요한 규칙을 보강합니다.
- 모바일: 현재 자산을 보존하고, 디자인 개편 방향이 정해진 뒤 이어갑니다.
- 가중치: 영역별로 MES 디자인을 따르는 정도를 조절하는 방식을 설계했습니다. 스킬이 요청을 해석하는 지침에 반영했고, 수치에 따라 생성·검사를 조절하는 기능은 다음 작업입니다.

가중치는 기본 `1`로 MES 기준을 유지합니다. 예를 들어 색상·폰트·메뉴는 그대로 두고,
특정 영역의 컴포넌트와 배치만 자유롭게 탐색하도록 지정하는 방식입니다.
신규 컴포넌트 제작 허용도 해당 영역에 따로 지정합니다.
